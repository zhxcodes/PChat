玩法与快捷键

本地指令不发送到服务端，不消耗额度
本地指令效果
/me 伸了个懒腰动作气泡（斜体），并照常发给角色
/roll 2d6+1掷骰子，显示每颗点数与合计（默认 1d20）
/coin抛硬币：正面 / 反面
/pick 火锅 烧烤 拉面随机选一个，也可用竖线分隔
/time本地时间 + 北京时间
/cmd 用更温柔的语气导演词：只影响下一次生成，不产生消息
/help在聊天页显示指令小抄
快捷键 / 鼠标作用
Ctrl + Shift + P命令面板（40 条命令）
Ctrl + Shift + L朗读最后一条 AI 回复
Ctrl + K搜索聊天记录
Esc关闭弹窗 / 停止朗读 / 取消引用
双击 AI 气泡朗读这一条
双击聊天空白撒一把花瓣
悬停联系人 → 图钉置顶 / 取消置顶
标题栏 时钟 图标 / 命令面板「时光机」回放某一天的对话（可暂停、倍速）
右键消息 →「生成分享卡片」把这条（含上一条问题）画成一张 PNG
