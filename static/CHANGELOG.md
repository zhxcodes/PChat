## 🎉 v1.0 (2026-11-20)

这是第一个大版本。变化集中在「怎么部署」和「怎么升级数据库」，聊天功能本身没有变。

### 🚀 部署方式变了

- 现在由 GitHub Actions 自动完成：推送代码后，先升级数据库结构，再构建并发布到 Cloudflare Pages。
- 仓库里不再有「Pages 构建时执行迁移」的脚本，也就不会出现「构建命令没配，建表被悄悄跳过」的情况。
- Pages 项目改为 **Direct Upload** 模式（不再直接监听 Git），发布完全交给流水线。

### 🗄️ 数据库升级更省心

- 需要在 GitHub 里加 3 个 Secret：`CLOUDFLARE_ACCOUNT_ID`、`CLOUDFLARE_API_TOKEN`、`D1_DATABASE_ID`。
- 第一次部署会**跳过建表**，只发布应用；补上 `D1_DATABASE_ID` 再跑一次，表就建好了。
  这两步是刻意分开的：先确认站点能打开、接口已连通，再初始化数据结构。
- 迁移记录（`d1_migrations`）由 Wrangler 自己维护，**你不需要执行任何 SQL**。

### 🧹 仓库更清爽

- 删掉了与根目录完全重复的 `static/functions/`：它会被当成静态文件公开，泄露服务端源码。
- `wrangler` 版本精确锁定，构建结果可复现。

### ⚠️ 从 0.14 升级要注意

- 如果旧项目是「Git 集成」方式部署的，需要新建一个 **Direct Upload** 项目，重新绑定 D1 / KV 与环境变量。
- 升级前先确认 D1 的 Time Travel 备份窗口（免费版 7 天 / 付费版 30 天），必要时先导出备份。

## 🚀 v0.14.4 (2026-11-15)

这一版是一次「用起来更顺」的补丁：登录多了账号级防爆破保护，手机上的聊天顶部栏不再挤成一排，管理后台的日志和角色列表也更清爽。没有数据库变更，部署后直接生效。

### 🔒 登录更安全

- 同一个账号在 15 分钟内连续输错 5 次密码，会被暂时锁定，提示「该账号尝试过于频繁，请稍后再试」。
- 锁定期内即使密码输对了也要等 15 分钟，防止有人换着代理 IP 硬试密码。
- 登录成功后这个失败计数会立刻清零，正常用户不会被误伤；只是大小写/空格不同的写法（Admin、admin）算同一个账号。
- 后台「登录日志」和「我的登录日志」里，被锁定的记录会显示原因「账号失败次数过多」。

### 📱 手机顶部栏不再拥挤

- 手机上聊天顶部只保留「搜索」，其余按钮（时光机、收藏、导出、AI 承诺、AI 设置、清空记录）收进右侧的「⋮」，点开是一个带图标和文字的网格面板。
- 点面板里的任何一项，效果和点原来那个按钮完全一样，点完面板自动收起。
- 右上角头像区域的按钮也做了同样收纳：手机只留「设置」和「退出登录」，命令面板、管理后台、系统管理、同步数据、个人资料都放进「⋮」。
- 没有选联系人、或者不是管理员时，面板里对应的项会自己隐藏，不会出现点了没反应的情况。
- 电脑端没有任何变化，所有按钮照旧铺开。

### 🛠️ 管理后台更好看

- 操作日志的「对象」列如果是一大段 JSON，超长内容会截断成「前 20 个字…」，鼠标悬停可以看到完整内容，表格不会再被撑歪。
- 操作日志和登录日志固定 400px 高度，超出部分在表格内部滚动，表头始终固定在顶部，不用再滚到页底去找列名。
- 角色管理列表去掉了手机上很挤的「温度」「Top P」「最大令牌」三列，只留「类型 / 名称 / 操作」，名称列占了一半宽度更好认；这三个参数仍然可以在「编辑角色」里改。
- 归档区的角色列表同样精简，「已归档」标记直接跟在名字后面。

### 📝 说明

- 不需要执行数据库迁移，也不需要新增环境变量。
- 版本号已更新为 v0.14.4；更新日志可在「设置 → 关于项目」里直接查看。

## 🚀 v0.14.0 (2026-11-14)

这一版是一次大升级：从「一个人用的聊天」变成「可以开给朋友用的多用户服务」——有管理员和普通用户、注册与邀请码、每个人自己的 API Key、登录记录、管理后台，以及一堆可以随时关掉的功能开关。

> ⚠️ **升级前必看**：这次动了数据库，**必须先执行迁移**，否则升级后会登录失败 / 页面报错。另外默认的 `admin / admin123` 账号不再自动创建。

### ⚠️ 升级步骤

1. 备份线上数据库（强烈建议）。
2. 依次执行 `migrations/001_batch1.sql`（如果以前没执行过）和 `migrations/002_security_and_audit.sql`。
3. 配置管理员：`ADMIN_USERNAME`、`ADMIN_PASSWORD`（用 secret，不要写进仓库）。
4. 配置主密钥：`wrangler pages secret put SECRET_MASTER_KEY`（用来加密用户自己的 API Key）。
5. 部署后用管理员账号登录，进入「系统管理」检查状态。

> 旧库里的 `admin` 账号迁移后会自动变成管理员，请**立即改密码**或停用。

### ✨ 功能更新

- **登录页可以注册了**：登录 / 注册两个选项卡。注册支持邀请码；默认注册是关闭的，需要管理员打开，并创建邀请码。
- **我的 API Key**：设置 →「我的 API Key」，可以保存自己的 DeepSeek Key。
  - 保存后聊天优先用你的 Key；不保存就用系统 Key。
  - Key 只以加密形式保存在服务端，保存后不会再显示出来；随时可以删除。
  - 管理员可以关闭这个功能，关闭后统一使用系统 Key。
- **我的登录日志**：设置 →「我的登录日志」，能看到最近 20 次登录的时间、成功 / 失败 / 被拦截、原因和 IP。只显示自己的记录。
- **系统管理页**（仅管理员可见，聊天页右上角盾牌图标）：
  - **系统初始化**：一眼看到主密钥、管理员账号、系统 Key、注册开关等是否就绪；可以一键生成新的主密钥，弹窗里有 10 分钟倒计时，复制后去 Cloudflare 配置。
  - **用户管理**：搜索用户、看今日 token，封禁 / 解封普通用户；封禁会立即把对方踢下线。
  - **用户用量**：今日 / 最近 7 / 30 / 90 天的 token 用量，按天柱状图和按用户排行。
  - **操作日志**：谁在什么时候封禁了谁、改了日志保留天数，都有记录。
  - **登录日志**：查看所有用户的登录情况，并设置日志保留天数（超期自动清理）。
- **功能开关**：管理员可以单独关闭收藏、表情回应、长期记忆、记忆提炼、承诺、洞察、统计、时光机、搜索、导出、导入；关闭后对应功能直接提示「已被管理员关闭」，聊天主流程不受影响。
- **账号状态**：账号被停用 / 封禁后无法登录，已经登录的会话也会立即失效。

### 🔒 安全修复

- 修掉一个严重问题：以前客户端可以自定义 AI 接口地址，而系统 Key 会跟着发过去 —— 理论上任何登录用户都能把自己的地址填进去，收走系统 Key。现在**系统 Key 只走管理员配置的地址**；自己的 Key 才允许自定义地址。
- 同理，Cloudflare AI Gateway 的令牌不再随自定义地址发送。
- `/api/admin/*` 下的管理接口现在强制要求管理员身份，普通用户访问一律 403。
- 跨域白名单改为环境变量 `ALLOWED_ORIGINS`；不配置时只允许同源访问，不再使用写死的域名列表。

### 🔧 升级后建议

- 不想开放注册：保持默认即可（关闭）。
- 想开放注册：在 `app_settings` 里把 `allow_register` 设为 `1`；如果保留邀请制，还需要先创建邀请码。
- 系统 Key 默认每用户每分钟最多 10 次请求，可以用 `SYSTEM_KEY_RATE_LIMIT` 调整；也可以设置 `USE_SYSTEM_API_KEY=0` 强制大家用自己的 Key。
- 用户自备的 Key 在换主密钥后会解不开，需要用户重新保存。

### 📝 说明

- 这一版的详细实现、接口与升级步骤见仓库根目录 `UPDATE_LOG_0.14.0.md`。
- 使用手册还没同步注册 / API Key / 管理页的图文说明，下一轮补。
- 版本号已更新为 `v0.14.0`。

### ✨ 功能更新

## 🚀 v0.12.0 (2026-10-24)

这一版解决两件事：**数据能带走了**（导入 / 完整备份），以及**聊天界面能按你的喜好捏**（背景、排版、动画）。升级不用动数据库。

### ✨ 功能更新

- **对话导入**：在「外观与玩法中心 → 数据与洞察」里选一个本项目导出的 JSON，就能把对话搬回来。
  - 先点「先预览」会告诉你「会写入多少条、跳过多少条重复」，你确认了才真的写库。
  - 三种落点：合并到现有角色（重复自动跳过）/ 覆盖该角色的历史 / 新建一个角色。
  - 整包备份也认：会按原来的角色 ID 逐个还原，不存在的自动新建。
  - 导入完会**清掉该角色的上下文缓存**，所以下一句 AI 回复就会用上新导入的历史（这一步很多人会漏）。
- **完整备份**：右上角按钮一键导出全部角色的对话（一个 JSON 文件），换设备、重装、迁移都靠它。
- **聊天背景**：6 套内置纹理（纸纹、点阵、网格、晨雾、夜雨、晚霞）随手点；也可以上传自己的图片，压到 1600px 存在本机浏览器（不占 localStorage、不上传服务器），还能调**模糊**和**遮罩浓度**，保证文字看得清。也支持填图片链接。
- **排版**：气泡形状（微信式 / 全圆角 / 直角）、内容行宽（全宽 / 舒适 900px）、头像大小（32/38/44）、时间标签（完整日期 / 相对时间，比如「今天 14:20」）。
- **动画与性能**：消息入场可以选「默认 / 左右滑入 / 仅淡入 / 无动画」；「性能模式」一键关掉所有动画和粒子，老设备、投屏、录屏时更稳。
- **年度热力图**：最近 53 周每天聊了多少条，一眼看出「哪天聊得最凶」。
- **本机用量**：云端消息数、浏览器缓存占了多大、背景图多大，还有一个「清理本地缓存」按钮（不动云端数据、不动你的外观设置）。
- **断网也能本地开发**：`npm run dev:offline`。以前断网时 `npm run dev` 会因为 AI 绑定要连云端而直接启动失败。
