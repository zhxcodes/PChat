系统初始化

主密钥（SECRET_MASTER_KEY）用于加密用户保存在数据库里的 API Key。 生成后请立即复制并配置到 Cloudflare，本页不会保存它。

人机验证（Turnstile）需要在 Cloudflare 配置两把密钥：站点密钥 TURNSTILE_SITE_KEY（公开，服务端会注入登录页）与服务端密钥 TURNSTILE_SECRET（保密，用 wrangler pages secret put 写入）。 两者都配置后，再到下面「功能开关（运行级配置）」里打开「登录 / 注册人机验证」。

新的主密钥

请立即复制并配置到 Cloudflare： Pages 项目 → Settings → Environment variables → 添加 Secret SECRET_MASTER_KEY， 或在项目目录执行：

wrangler pages secret put SECRET_MASTER_KEY
10:00

倒计时结束后本页不再显示密钥；密钥只存在当前页面内存里，刷新即丢失。 更换主密钥后，已保存的用户 API Key 将无法解密，需要用户重新保存。
